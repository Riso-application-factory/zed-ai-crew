Quy tắc làm việc với Crew

Đọc brief, task và các mục spec được task dẫn. Brief là nguồn yêu cầu; không tự thêm yêu cầu. Tài liệu làm việc cho agent nằm ở AGENTS.md.

Lệnh kiểm chứng

cargo check -p crew -p crew_acp -p crew_mcp -p crew_github -p crew_models -p crew_ui
cargo test -p <crate_bị_sửa>
./script/clippy
cargo fmt --all -- --check
cargo run
cargo test -p crew need61
CREW_CONTRACT=1 cargo test -p crew_acp --test contract -- --ignored --test-threads=1

Contract test gọi adapter ACP thật và tốn hạn mức. Chỉ chạy khi task yêu cầu, đổi bản ghim adapter hoặc trước manual test, có Human sẵn sàng đăng nhập. Test thường không được gọi provider. Dùng cấu hình executable của harness; không đọc file đăng nhập để làm test đạt.

Bản debug bật bằng "feature_flags": { "crew": "on" } trong settings user. Mặc định staff vẫn tắt; release thông thường tắt tới T7.8. crew_ui::init chạy đồng bộ trong zed::initialize_workspace, sau command_palette::init. Không chuyển về zed::init sớm: thao tác tạo entity có thể chạy callback hoãn trước khi filter được tạo.

Ranh giới

  • Core chỉ sửa tại H1–H11 và trong danh sách file task cho phép: main.rs (H1); acp/v1.rs (H2/H3); acp_thread.rs (H4); agent_ui (H5); onboarding (H6); settings_content/settings_ui (H7); feature_flags/flags.rs (H8); zed.rs (H9); agent_server_store.rs (H10); custom.rs và luồng đăng nhập (H11).
  • NEED 61: chỉ điều khiển provider qua ACP; không đọc/ghi thư mục home provider, gọi API riêng hoặc CLI ngoài adapter ACP. Không đọc/xóa kho hội thoại provider.
  • Task dùng nhánh crew/<task-id>-<tên>; code spike ở nhánh spike/…, không merge code thử vào main.
  • Không đưa secret, email, account ID hay log thô vào code, fixture, PR. Kiểm sandbox bằng file bí mật giả; che dữ liệu trước khi lưu.
  • Mọi hành vi Crew sau CrewFeatureFlag; tắt flag thì như upstream. Sửa lỗi đăng nhập H11 là ngoại lệ đã nêu. Giữ nguyên thông báo review thủ công đầu README.

Chiều phụ thuộc

zed → crew_ui → crew
crew → crew_acp → agent_servers, acp_thread, project
crew → crew_mcp → context_server
crew → crew_github → http_client, credentials_provider, git
crew → crew_models → http_client
zed → crew_mcp (chỉ cầu nối H1)
agent_ui → agent_servers

agent_ui, agent_servers, acp_thread không phụ thuộc Crew. crew_acp không phụ thuộc crew; dùng trait do crew hiện thực. Registry nằm ở agent_servers. Công cụ Crew cụ thể nằm trong crew, không ở crew_mcp.

Điều kiện xong

Viết test nghiệm thu trước code, kiểm fail đúng lý do, làm đúng phạm vi rồi chạy kiểm chứng task và lệnh chung. Task tài liệu kiểm liên kết và nguồn. Markdown mới bằng tiếng Anh; HTML tương ứng bằng tiếng Việt, cập nhật cùng phiên. UI cần chạy app thật và có bằng chứng.

PR ghi task ID, thay đổi, lệnh/kết quả và phần chưa kiểm; theo quy tắc Release Notes. Dùng PR review có thread. Một agent khác, context mới, kiểm lại và trả pass/fail kèm bằng chứng. Chỉ merge khi cổng tự động và độc lập đều đạt; Human quyết định câu hỏi sản phẩm. Không báo xong khi còn cổng chưa đạt; hiện NEED 58 vẫn chưa đạt vì repo PUBLIC.
