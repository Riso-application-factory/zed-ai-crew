Khác biệt fork và cổng chưa đạt

  • H4 đã chốt cách xử lý: TokenUsageUpdated trên fork không mang payload; upstream mang OutputTokensUpdate. Spec H4 và T1.10/T1.11 đã yêu cầu giữ nguyên event và API v1, thêm event chi tiết mang used, size, _meta. M1 mới hiện thực.
  • Fork cố ý ghim ACP =3.4.0, upstream =3.5.0; cả hai bật schemars, unstable, unstable_protocol_v2. Chấp nhận bản ghim cho M0, S6 kiểm đúng phiên bản fork.
  • Builder notification hiện nằm ở client_builder; chưa có handler auth extension hay wrapper steering. update_usage chưa giữ metadata cấp trên; update v1 lạ vẫn bị bỏ. API quyền, file, MCP, worktree và Seatbelt còn dùng được.
  • Agent::server vẫn là chỗ tạo CustomAgentServer. Nhánh subagent vẫn bỏ composer. Thread import chưa lọc cwd. Key môi trường OPEN_AI_API_KEY vẫn sai. Npx vẫn dùng trần phiên bản và binary vẫn dọn cache cũ: Crew cần ID/cache riêng.
  • Ba file gốc AGENTS.md, CLAUDE.md, GEMINI.md là symlink tới .rules ở cả hai cây. Fork thêm một mục Crew ngắn cuối .rules.
  • NEED 58 chưa đạt: lệnh GitHub với repo tường minh Riso-application-factory/zed-ai-crew trả PUBLIC. Chưa đổi visibility.
  • Brief v3.5, spec v2.3 và kế hoạch đã có; báo cáo S1–S5 đóng gói dữ kiện Human cung cấp, không gọi provider mới.
